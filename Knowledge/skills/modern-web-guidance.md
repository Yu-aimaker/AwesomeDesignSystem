# Modern Web Guidance

## 概要

Modern Web Guidance は、エージェントに Web の現行作法を渡すスキル集である。配布リポジトリは GoogleChrome/modern-web-guidance、パッケージ版は 1.0.0（2026-11-11 に package.json を読んだ）。README は、Chrome、Edge、Firefox、MDN がスチュワードだと書く。AwesomeDS はこれより広く、深く、新しい作法を持つ競合であり、ガイドの本文は写さない。

## 要点

- 文書の入口: https://developer.chrome.com/docs/modern-web-guidance （2026-11-11 に HTTP 200）。
- リポジトリ: https://github.com/GoogleChrome/modern-web-guidance 。2026-11-11 の GitHub API で 4,352 stars、最終 push 2026-11-10、archived ではない。license フィールドは Apache-2.0。
- ライセンス: ソフトウェアは Apache-2.0（ルートの LICENSE と package.json）。README は、guides/ の文書を CC-BY-4.0 と書く。
- ガイドの中身、コマンド、件数はここへ写さない。必要なら上のリンクを開く。

## AwesomeDS への反映

- 反映済み: `foundations/principles.md` の Scope、`DESIGN.md` のポインタ、`AGENTS.md`。参照リンクだけを置き、ガイドは写さない。モデルの記憶より、AwesomeDS の規則と開いて確認した一次情報を優先する。
- 反映不要: ガイド本文の転記。すでに十分扱っている点はリンクに留める。
