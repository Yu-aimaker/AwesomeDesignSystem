# キャラクター設計（段階1）

体験サイト用の独自キャラクターの設定。描画、モーション実装、`/character` は段階2。この文書がデザイナーへの渡し物。

正本のマークは `docs/assets/brand/icon.svg`。角丸 8/32 のタイル、幾何学的な「A」、横棒だけ `#2f5bea`。この文法から手で描く。Duolingo の形、ポーズ、配色は使わない。外部のイラスト素材も使わない。ラスタの自動生成も使わない。

## 性格

静かで、形は幾何学、動きは短い。営業キャラクターではない。ドキュメントを読むときの目印で、製品に同梱するブランドマスコットではない。

## 役割

AwesomeDS は、ブランドを持たないプロダクトがそのまま使える汎用のデザインシステム（README）。キャラクターは体験サイトの中だけに置き、利用側の UI には出さない。

## 出す場所

- 段階2の `/character` と `/en/character`。モーションの見本と、設計の短い説明。ページは docs の体裁（見出しと節）。ヒーローや申し込み導線は置かない。
- このディレクトリに置く静止画（段階2で書き出す）。

`/character` 以外では自動再生しない。待機は約3周で止まり、一時停止できる（WCAG 2.2.2）。動きは transform と opacity だけ。移動は 8px 以内。

## 出さない場所

- ヘッダーとモバイルシート。左上は静的なアイコンだけ（段階2の BrandMark）。
- 404、空状態、トースト、フォームのエラー。
- 製品 UI のクロム、ボタンの中、ローディング。
- マーケティング用のヒーロー。このサイトは LP にしない。

ヘッダーのアイコンとマスコットを同時に動かすと、マークが二つになる。ページの外では出さない。

## アクセシビリティ

- キャラクターは `role="img"`。名前は表示言語に合わせる。
- 今のポーズ名はライブリージョンで読み上げる。意味は色ではなく形（腕の位置）で伝える。
- 操作はボタン。フォーカスリングは既存のトークン。
- OS の `prefers-reduced-motion: reduce` と、ページ上の縮小モーションスイッチの両方で、アニメーションを止める。各モーションは静止ポーズに置き換える。点滅で代替しない。サイト全体の `animation-duration: 0.01ms` には頼らない（ループが最終フレームでちらつく）。

## 名前の候補

呼び方は未定。段階2の実装では定数1か所に置き、差し替えは1行にする。コード上の識別子は `mascot` のまま。

| 候補 | 読み | 理由 |
|---|---|---|
| エース | Ace | マークの「A」から。短い。 |
| タイル | Tile | 胴体が角丸タイルであること。 |
| マーク | Mark | ブランドマークが動く、という意味。 |

## 見た目（デザイナー向け）

アイコンと同じ文法にする。

- 塗りだけ。グラデーションなし。線のアウトラインは付けない。
- 角丸の比率はタイルの 25%（8/32）。
- 胴体は上すぼまりの角丸タイル。頂点はアイコンの「A」と同じ直線。文字「A」そのものは描かない。正方形のまま手足だけ足すと、ヘッダーのアイコンと取り違える。
- 色は3つ。胴体は ink、目と口は canvas、アクセントは1色（アイコンの横棒をベルトにする）。オレンジは使わない。頬の色は付けない。
- 手足は角丸の矩形。腕は別グループ（肩を原点に回す）。足は短い。目は canvas の楕円（まばたきで縦に潰す）。口は細い線で任意。
- グリッドは 64×64 または 96×96、座標は整数。32px でも頂点とベルトが残ること。16px は対象外（ファビコンと役割がぶつかる）。

### 色

| 部分 | トークン | ライト | ダーク |
|---|---|---|---|
| 胴体 | `--ds-ink` | `#0a0a0a` | `#fafafa` |
| 目・口 | `--ds-canvas` | `#ffffff` | `#0a0a0a` |
| ベルト | `--ds-accent` | `#2f5bea` | 既定は `#2f5bea`。サイトのダークではトークンが `#7a9cff` になる |

`web/src` には生の hex を書かない。`var(--ds-ink)`、`var(--ds-canvas)`、`var(--ds-accent)` を使う。書き出し SVG（`docs/assets/brand/`）はアイコンと同じく実値でよい。canvas と surface の両方に置いて読めること。

ヘッダーマークの横棒を固定の `#2f5bea` にするか、`--ds-accent` に追従させるかは段階2の未決。キャラクターのベルトはトークン追従を既定にする。

### サイズ

| 用途 | サイズ |
|---|---|
| `/character` の見本 | 96px 以上。高さは固定し、レイアウトをずらさない |
| ポーズ一覧 | 64px |
| 最小 | 32px で輪郭が残る |

## モーション（デザイナー向け）

UI のモーション上限（300ms、ループなし）は製品フィードバック用。キャラクターはイラストなので、長い時間は `/character` だけに限る。イージングは `--ds-ease-out`。跳ねはイージングで出し、damping 20 未満のスプリングは使わない。

| id | 内容 | きっかけ | 時間 | 縮小モーション時の静止 |
|---|---|---|---|---|
| idle | 呼吸。translateY 2px、scaleY 0.98。約3周で自動停止。一時停止あり | ページの既定 | 約 2.4s / 周 | 中立 |
| wave | 片腕を肩から ±20°、2往復 | ボタンだけ | 約 800ms | 片腕が上がったまま |
| happy | 小さな跳躍（8px 以内）、両腕を上げる。アクセントの粒は 3〜4 個、opacity だけ | ボタンだけ | 約 700ms | 両腕が上がり、粒が見える |
| blink | 目の scaleY を 0.1 まで | ボタン、および idle の途中で時々 | 約 150ms | 目を一度閉じて開く。opacity の入れ替えは 100ms 以内 |
| nod | 胴体を 4px 下げる | ボタンだけ | 約 400ms | 少しうつむいたまま |

ワンショットは終わると idle の静止に戻る。ヘッダーではどのモーションも動かさない。
