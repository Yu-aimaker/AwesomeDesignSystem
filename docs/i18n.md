# サイトの多言語対応（web/）

`web/` は日本語と英語を出す。既定は日本語で、URL は変えていない。英語は `/en` 接頭辞で同じページを出す。

## 仕組み

| 部品 | ファイル | 役割 |
|---|---|---|
| ロケール定義 | `web/src/i18n/locales.ts` | `locales`、`Localized<T>`、URL と locale の変換 |
| Provider | `web/src/i18n/context.tsx` | URL から locale を決める。`<html lang>` と `hreflang` の alternate を出す。`useT` / `useLocale` |
| ルーター | `web/src/i18n/router.tsx` | `Link` / `NavLink` / `Navigate` / `useNavigate` の locale 付き版。サイト内ではこちらを import する |
| 言語切替 | `web/src/layout/LanguageSwitch.tsx` | 同じページの他言語版への通常のリンク（`hreflang` と `lang` 付き） |
| カタログ | `web/src/i18n/messages/<area>.ts` | ページや部品ごとの文言。`en: typeof ja` で形を強制する |

locale は URL だけから決まる。保存した設定や Accept-Language による自動リダイレクトはしない。共有したリンク、戻る / 進む、表示中の言語が常に一致するため。

## 文言を足す

```ts
import type { Localized } from "../locales";

const ja = {
  title: "出典・ガイドライン",
  count: (n: number) => `${n} 件`,
};
export type SourcesMessages = typeof ja;
const en: SourcesMessages = {
  title: "Guidelines and sources",
  count: (n) => `${n} items`,
};
export const sourcesMessages: Localized<SourcesMessages> = { ja, en };
```

コンポーネントでは `const t = useT(sourcesMessages)` で取り出す。データに文言を持たせるときは `label: Localized<string>` にして `label[locale]` で読む。

## 言語を足す

1. `locales.ts` の `locales` と `localeMeta` に追加する（`prefix` は `/xx`）。
2. `cd web && pnpm typecheck`。`Localized<T>` を満たさないカタログとデータが全部エラーになるので、順に埋める。
3. `scripts/screenshot.mjs` の `routes` に `/xx/...` を足し、`wantLang` の判定を更新する。


## 訳していないもの

- `Knowledge/` の Markdown 本文。英語ページでは本文を `lang="ja"` で囲み、日本語である旨の注記を出す。タイトル、カテゴリ、出典リンクは英語。
- `AwesomeDS/data/*.json` 由来の文（スタックの理由、パレットやフォントの注記）。生成データなので手で訳さない。英語ページでは `lang="ja"` を付けて出す。
- 日本語の組版を見せる見本文（和文フォント、行間、palt など）。内容そのものなので日本語のまま `lang="ja"` を付ける。

`AwesomeDS/foundations/*.md` はもともと英語で書かれているので、そのまま両方の言語で出す。
